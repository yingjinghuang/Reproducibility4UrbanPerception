# Derived Metadata

This directory is the target location for the released derived metadata package. After unpacking `polygeovision_metadata.tar.gz`, it contains:

- image-level metadata and reverse-geocoded spatial hierarchy
- TrueSkill Q-scores and split assignments
- image complexity and label-dispersion covariates
- per-image and per-place stability tables
- multi-scale variance decomposition outputs
- ensembling, multi-split, and ICC robustness summaries

Raw Place Pulse 2.0 imagery is not included.

Download DOI: https://doi.org/10.5281/zenodo.20561660
